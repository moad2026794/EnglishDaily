# إنجليزيتي اليومية (English Daily)

تطبيق أندرويد (Kotlin + Jetpack Compose) لمتابعة تعلم الإنجليزية يوميًا. يعمل دون إنترنت.

## الدرس اليومي (5 خطوات)
1. 10 كلمات: نطق + ترجمة + كتابة الكلمة من الذاكرة + كتابة جملة وقراءتها بصوت التطبيق
2. قصة قصيرة تُقرأ بصوت واضح (سرعة بطيئة/عادية/سريعة)
3. قاعدة نحوية مع أمثلة منطوقة
4. تسجيل صوتي لا يقل عن 50 ثانية، يُسمّى باسم الموضوع
5. اختبار (12 سؤالًا: معاني، استماع، قصة، قاعدة)

إضافات: سلسلة الأيام، مراجعة وبطاقات الكلمات، إحصائيات، تذكير يومي.

## الحصول على APK
**GitHub Actions:** ارفع المجلد إلى مستودع GitHub، ثم من تبويب Actions > Build APK
نزّل الملف من Artifacts (EnglishDaily-APK).

**Android Studio:** File > Open على المجلد، ثم Build > Build APK(s).

## إضافة دروس جديدة
عدّل `app/src/main/assets/lessons.json` (فيه حاليًا 30 درسًا) بنفس الصيغة (10 كلمات + قصة + قاعدة لكل درس).
التطبيق يعيد الدروس من البداية عند انتهائها.
